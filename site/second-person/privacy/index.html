第二人称隐私政策

政策草案 · 正式发布前确认生效日期 · 联系：dosomethinginteresting@outlook.com

运营者：Charry yang（个人，美国加利福尼亚州）

第二人称是一款助你打破信息茧房的 Android 陪伴应用。应用不要求注册账户，开发者不运营用于保存用户对话的服务端。

我们处理的信息

当你允许模型处理并点击发送时，应用会把本次输入、必要的最近对话、你亲自确认的记忆和所选交流方式直接发送给 DeepSeek API，用于生成回复。请求使用你提供的 DeepSeek API Key。即使你尚未开始聊天，主动点击“测试连接”也会用该 Key 向 DeepSeek 发送固定的简短测试语句，可能消耗账户额度。DeepSeek 对这些信息的处理适用你与 DeepSeek 之间的条款和隐私政策。

只有你主动点击“检索新来源”时，应用才把检索框内的完整文字和你提供的 Tavily API Key 发给 Tavily Search API。检索框不会自动带入聊天或记忆；请不要在其中填写私人敏感信息。搜索候选只在当前页面暂时显示，不写入历史。

选择多篇资料并确认“对照这些资料”后，应用会把问题、所选网页的标题、发布信息、读取时间及有限长度的原文摘录发送给 DeepSeek；此请求不附带聊天历史或个人记忆。只有你再点击保存，资料对照才进入本机记录。Tavily 对检索文字的处理适用你与 Tavily 之间的条款和隐私政策。

当你主动读取公开网页时，应用会访问该 HTTPS 网页并在本机生成有限长度的摘录。只有你再次确认带入对话后，摘录才会随对话发送给 DeepSeek。目标网站会按互联网的通常方式看到请求所需的网络信息。

只有设备提供 Android 本机语音识别服务时，应用才请求麦克风权限并调用该服务。转写文字先进入输入框，由你核对后发送；本应用不保存录音。系统识别服务的实现仍由设备提供方负责。

当你主动点击“手动检查更新”时，应用会从 second.translens.cn 读取公开版本信息，不发送对话、记忆或 API Key。网站会按互联网通常方式看到请求所需的网络信息；应用不会自行下载安装包。

本机保存和安全

普通对话、你确认的记忆、主动保存的片段和资料对照、“手动回访”中填写的行动、结果与状态，以及偏好，保存在设备本机。保存的资料对照可能包含问题、AI 归纳、原文短引句、网页标题、原链接、页面标示的发布信息和读取时间。对话与记录未另做应用级加密；两种 API Key 则经 Android Keystore 保护的 AES-GCM 密钥加密，并存放在不参与备份的目录。应用已配置不参与 Android 系统云备份和设备迁移，也不提供应用内同步；设备厂商的其他迁移机制不在本应用控制范围内。网络请求只使用 HTTPS。

你的选择

你可以不允许模型处理并浏览应用；此时不会生成模型回复，除非你主动测试连接，否则不会向 DeepSeek 发起模型请求。你可以关闭新对话历史、开启离开后清除的临时对话、删除单条记录、移除 API Key，或在设置中删除全部本机数据。“删除全部”会停止应用中的进行中操作，并清除本机对话、记忆、保存片段和资料对照、手动回访、偏好及两种 API Key；若删除失败，应用会提示重试。

删除或撤销授权不能撤回已经发给 DeepSeek、Tavily、所访问网页站点或系统语音服务的数据。开发者无法通过本应用删除第三方按其政策保留的请求记录；撤销或轮换 Key、请求删除其账户侧数据，应通过相应服务商的渠道办理。

诊断和监控

首版不集成第三方崩溃采集 SDK。官网直装版本不会自动向开发者发送崩溃报告。你主动发邮件联系支持时，我们会收到你提供的邮箱地址、来信内容和附件，仅用于回复与排查；请勿发送 API Key、完整对话或未经去敏的截图。若需删除支持邮件，可通过同一邮箱提出。

未成年人、专业建议和紧急情况

应用面向具备独立同意能力的用户，不以儿童为目标用户。模型回复可能错误，不能替代医疗、心理危机、法律、财务或紧急救援服务。遇到紧急危险请联系当地紧急服务与可信任的人。

变更与联系

政策发生实质变化时，会在应用和官网更新生效日期。隐私问题请联系：dosomethinginteresting@outlook.com。
