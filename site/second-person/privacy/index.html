第二人称隐私政策

政策草案 · 正式发布前确认生效日期 · 联系：dosomethinginteresting@outlook.com

应用不要求注册账户，开发者不运营用于保存用户对话的服务端。

我们处理的信息

当你点击发送时，应用会把消息、必要的最近对话上下文以及你亲自确认的记忆直接发送给 DeepSeek API，用于生成回复。请求使用你提供的 DeepSeek API Key。DeepSeek 对这些信息的处理适用你与 DeepSeek 之间的条款和隐私政策。

只有你主动点击“检索新来源”时，应用才把检索框内的完整文字和你提供的 Tavily API Key 发给 Tavily Search API。检索框不会自动带入聊天或记忆；请不要在其中填写私人敏感信息。搜索候选只在当前页面暂时显示，不写入历史。Tavily 对检索文字的处理适用你与 Tavily 之间的条款和隐私政策。

选择多篇资料并确认“对照这些资料”后，应用会把问题和有限长度的原文摘录发送给 DeepSeek。只有你再点击保存，资料对照才进入本机记录。

当你主动读取公开网页时，应用会访问该 HTTPS 网页并在本机生成有限长度的摘录。只有你再次确认带入对话后，摘录才会随对话发送给 DeepSeek。目标网站会按互联网通常方式看到请求所需的网络信息。

当你主动使用语音输入时，应用调用设备上可用的 Android 语音识别服务。文字先进入输入框；本应用不保存录音。识别位置和提供方取决于设备设置。

当你主动点击“手动检查更新”时，应用会从 second.translens.cn 读取公开版本信息，不发送对话、记忆或 API Key。网站会按互联网通常方式看到请求所需的网络信息；应用不会自行下载安装包。

本机保存和安全

对话、确认的记忆、保存片段和偏好保存在本机。API Key 经 Android Keystore 保护的 AES-GCM 密钥加密。应用全部数据均排除在 Android 云备份和设备迁移之外，网络请求只使用 HTTPS。

你的选择

你可以关闭模型处理、关闭新对话历史、开启临时对话、删除单条记录、移除两种 API Key，或在设置中删除全部本机数据。开发者无法通过本应用删除 DeepSeek 或 Tavily 账户侧可能依约保留的数据。

诊断和监控

首版不集成第三方崩溃采集 SDK。官网直装版本不会自动向开发者发送崩溃报告；如果你主动联系支持渠道，可以自行选择提供问题描述和去敏截图。

能力边界

应用面向具备独立同意能力的用户，不以儿童为目标用户。模型可能出错，不能替代医疗、心理危机、法律、财务或紧急救援服务。

变更与联系

政策实质变化时会更新生效日期。隐私问题请联系 dosomethinginteresting@outlook.com。
