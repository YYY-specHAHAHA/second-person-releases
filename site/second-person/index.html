关于 API Key 的使用

对话需要你自己的 DeepSeek API Key；主动检索公开来源时，才需要 Tavily API Key。两种密钥加密保存在本机，请求会分别直接发给对应服务商。费用与额度以你的服务商账户为准。

安装时，照着系统提示走就好。

官网下载属于 Android 的应用商店外安装。你需要允许当前浏览器安装这一次应用；安装后可按自己的偏好关闭该许可。不要关闭系统安全扫描。

  1. 从本页下载正式签名 APK。
  2. 打开文件，按 Android 提示允许当前浏览器安装。
  3. 安装后在应用内填写自己的 DeepSeek Key，或先进入看看。
